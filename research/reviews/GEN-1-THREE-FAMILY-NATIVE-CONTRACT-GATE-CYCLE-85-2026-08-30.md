# GEN-1 — three-family native-contract gate, cycle 85

## Scope

This was one design/service-only wake after valid negative EXP-0059. It created no experiment plan, candidate, scoring seed, runner invocation, result, dependency, external model/API or protected evaluator migration. The active DronePropA v5 cohort and all immutable history remain unchanged.

The audited proposal combined `nonlinear_local_state_transfer_v1`, `continuous_event_predictive_state_v1` and `heldout_dronepropa_factor_recombination_v5`. Acceptance required one lossless source-identical public contract, no family labels or hand-written ontology, a router no better than three-family chance plus `0.10`, and a repeated latent predictive factor that could distinguish pooled representation learning from three implicit specialists.

The machine-readable gate is `research/reviews/GEN-1-THREE-FAMILY-NATIVE-CONTRACT-GATE-CYCLE-85-2026-08-30.json`.

## Native contracts

| Family | Public training | Public query | Target |
| --- | --- | --- | --- |
| nonlinear local state | 128 discrete local-rule cases | graph with K descriptors, K states, K edge pairs, source and pulse | three categorical integers |
| continuous event | one `108 × K` float episode | `D × K` float matrix | D continuous scalars |
| DronePropA v5 | K whole-flight supports, each `128 × 320` | fixed 320-value history | six continuous state values |

These are not three renderings of one hidden mechanism. They use different causal units, output symmetries and update semantics. Converting them into a common learner interface requires evaluator-authored meanings such as graph node, action, regime, control, state and rollout. That mapping is the forbidden ontology rather than a learned representation.

## Router and serializer gates

Using only fixed development seeds `1103/2207/3301`, K=`8/32` and no predictive loss, a rule based on graph-edge presence, container rank, query width and target arity classified all `18/18` audited worlds. Accuracy `1.0` exceeds the allowed `0.4333` ceiling.

The existing lossless family-neutral encoder does not accept NumPy arrays. A generic array extension must preserve rank, shape and numeric kind, which retains the perfect router. Padding every query to width 320 and every target to six values would expose padding occupancy; resampling or dropping graph structure would be lossy and change the tasks. There is therefore no honest shape-equalization repair.

This proposal is also redundant with the earlier cycle-61 and cycle-68 audits. Those audits already showed exact family routing and no common latent factor in reduced heterogeneous subsets. Adding DronePropA makes routing easier and does not create a shared mechanism.

## EXP-0059 factual correction

The EXP-0059 analysis correctly records the empty implementable frontier but gives the wrong proximate cause. Runner `_frontier` excludes timeout rows before constructing metric axes. The frontier was empty because every completed implementable candidate failed the configured `0.95` capability gate, not because `empirical_gaussian_joint_v1` timed out. The timeout remains a valid durable failure and unresolved baseline comparison, but it did not erase Pareto axes. This correction is append-only; the completed analysis and result remain unchanged.

The two condition-support controls also remain privileged diagnostics rather than empirical oracle lower bounds: their rollout NRMSE `122.119901` and stability `0.498942` show that exact-condition support did not bound test error. No future DronePropA plan may use `oracle_gap_closed` as ideal-bound evidence until a separately versioned cohort renames or replaces those controls. Because this gate rejects the proposed next cohort and no new DronePropA scoring is authorized, no protected migration is performed in this wake.

## Decision

`reject_before_implementation` for the proposed three-family learner. Do not create a cross-family evaluator, new hypothesis, candidate or EXP-0060 from this set. This rejects the evaluator/question pairing, not the possibility of transferable representations.

Confidence is `1.00` in the audited native interfaces, `1.00` in the `18/18` router result, `0.99` that a lossless common serializer preserves a task-identifying structural signal, and `0.95` that hand alignment would move the scientific answer into the evaluator.
