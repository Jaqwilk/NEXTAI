# Pre-seed control-semantics finding

The start gate found that the existing literature ledger and cycle-63 review
already identify Sequitur/Re-Pair as the classical explanation for recursive
motif reuse. V6 contained eight sequence/statistical controls but no actual
grammar transform. Scoring a prospective equality-grammar learner against that
matrix could therefore confuse a renamed Re-Pair transform with a new learned
mechanism. The defect was found before hypothesis creation, candidate
implementation or seed realization, so this wake was converted to maintenance.

# Minimal correction

`heldout_parallel_masked_infilling_v7` directly re-exports the v6 evaluator and
preserves the corpus, whole-file split, masks, byte permutation, simultaneous
rounds, matrix, metrics, directions, budgets, seed policy, three prospective
roles and all eight historical controls. It adds only the mandatory
`re_pair_grammar_masked_byte` implementable control.

The control performs batch Re-Pair: at each step it chooses the most frequent
adjacent symbol pair occurring at least twice, resolves ties by first corpus
occurrence, creates one nonterminal and replaces non-overlapping occurrences
left-to-right. It expands rules recursively and stops after 64 rules. The
masked adapter uses only public anchors, combines grammar votes with a
Dirichlet-1/2 empirical byte prior, never updates at query time and explicitly
charges fitting, replacement, expansion, alignment, query work and state. This
is an honest Re-Pair transform with a separately specified evaluator adapter,
not a claim that Re-Pair itself defines probabilistic masked inference.
