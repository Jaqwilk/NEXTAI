## Evidence-based selection

Three mechanisms were compared against the append-only portfolio. Reversible
program-state induction was rejected because HYP-0009 already removed ready
programs and found exact MDL both exact and cheaper than the learned VM.
Experience-sparser conditional execution was rejected because HYP-0010 already
found the direct flat program cheaper than learned sparse routing, and a new
router would reopen the same family without removing stable task IDs.

Locally learned error-correcting latent codes were selected at low prior
plausibility because the missing causal factor has not been tested: in EXP-0034
the representation's majority redundancy was supplied by the evaluator, while
the requested mechanism must learn useful redundant coordinates from raw
observations. SRC-0081 and SRC-0082 make sparse parity decoding and local
bit-flipping strong prior-art explanations, not novelty claims. The existing
masked-infilling corpus can directly test denoising, parallel local correction,
unseen files, byte relabeling, three span lengths and full work, so no new toy
benchmark or data schema is needed.
