# Cycle 192: associative alias rejection and stack-depth v8 service migration

## Scope

This was exactly one no-scoring service cycle. It created no hypothesis,
experiment plan, runner seed, candidate implementation or result. The cycle
first tested whether the requested locally plastic sparse associative state was
a genuinely new causal mechanism, then froze the smallest distinct benchmark
contract needed for the next breadth scout.

## Observation: the proposed associative direction is an alias

The proposed learned addressing plus local Hebbian/Oja update is already
covered by prior NEXTAI evidence rather than merely resembling it by name:

- HYP-0031 / EXP-20260901-0004 tested event-sparse associative plasticity. Its
  sparse-cost signature appeared, but persistence was more accurate, so the
  exact family was falsified.
- EXP-20260830-0043 directly compared additive and delta fast weights, LMS,
  kernel dictionaries and replay under online update. Shared transfer failed.
- EXP-20260830-0032 tested vector-symbolic/dense associative routing and was
  dominated by exact storage.
- frozen random addressing is already represented by random-projection hash and
  indexed local-operator controls; decreasing warm inference aliases the
  previously tested cache/search/surprise-gate family.

Renaming the same update law would add no discriminating information. The
locally plastic associative direction is therefore rejected before migration,
preregistration, implementation or scoring. This is not new evidence and does
not alter any hypothesis confidence.

## Distinct identifiability contract

The existing held-out masked corpus contains real balanced Python delimiter
traces at exact test depths 3, 4 and 5. Tokenization found 54, 21 and 6 traces,
respectively, with no bracket mismatch. Training and validation can be limited
to traces of maximum depth 2, creating a direct systematic depth-extrapolation
test without synthetic worlds or a new dataset.

`heldout_parallel_masked_infilling_v8` is a separate prospective cohort. The
evaluator privately extracts balanced delimiter events, excludes strings and
comments, applies the runner-random byte permutation, and exposes only opaque
byte traces with one masked deepest closer. Candidate code receives no path,
token kind, raw delimiter, family rule or handwritten ontology.

The future shared role is `learned_pushdown_masked_byte`; its two required
source-identical causal nulls are
`source_identical_finite_state_pushdown_masked_byte` and
`source_identical_frozen_pushdown_masked_byte`. They may differ only in the
registered pushdown, bounded finite-state or frozen-transition intervention.
The nine existing masked controls remain mandatory.

## Interpretation and decision

The benchmark measures a qualitative signature absent from the random-span
infilling score: learning a state update from shallow observations and applying
it beyond trained compositional depth. It is deliberately small and uses the
existing immutable source files and public candidate contract. The evaluator
does contain a private Python-delimiter target definition, but that ontology is
used only to select ground truth and is never supplied to an implementable
candidate.

Decision: reject the associative alias and activate v8 only after all service
gates pass. Cycle 193 must preregister, minimally implement and score exactly
one quick learned-pushdown scout. No second service-only wake is allowed before
that score. A one-seed positive may only authorize unchanged replication; a
negative ends the exact learned transition rule without tuning.
