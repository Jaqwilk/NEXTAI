# GEN-1 — multi-world transfer redundancy and identifiability audit, cycle 61

## Scope

This was one design/service-only cycle after valid negative EXP-0056. It created no experiment plan, candidate, scoring seed, runner invocation, result, dependency, external model/API or protected evaluator change. The active `heldout_mechanism_recombination_v2` cohort and all immutable history remain unchanged.

The requested question was whether three or four existing heterogeneous benchmark families can support one unchanged family-blind learner, unseen test worlds, source-identical independent fitting, contextual Chow–Liu, empirical-joint, autoregressive and oracle controls, and complete cost accounting.

## Existing implementation audit

The requested infrastructure already exists in three historical versions rather than being absent. `cross_family_shared_representation_v2`, `cross_family_shared_representation_v3` and `cross_family_relation_fragment_transfer_v4` reuse four frozen families: context-specific probabilistic circuits, action-conditioned predictive equivalence, nonlinear local state transfer and behavioral program composition. They use fixed training seeds `1103/2207/3301`, runner-random disjoint test worlds, a lossless family-neutral serialization, source-identical shared/independent learners, native contextual Chow–Liu, empirical-joint and autoregressive suites, a privileged oracle, and acquisition/fit/meta-fit/query/update/state/bytes/R16 accounting.

Three scientifically valid shared mechanisms have already failed this boundary. Recurrent-linear EXP-0048, recurrent-dictionary EXP-0050 and relation-fragment EXP-0052 achieved overall transfer `0.015625`, `0.046875` and `0.223958`; every result had minimum-family accuracy `0.0`. In EXP-0052 the shared-minus-independent advantage was only `0.026042` overall and exactly `0.0` on minimum-family accuracy. Native contextual Chow–Liu achieved `0.989583` overall and `0.958333` minimum-family accuracy and was the only accuracy-gated implementable Pareto point.

## Identifiability gate

The prior fixed-training audit covered K=`8/32`, D=`1/4/6` and all three training seeds. A family-neutral profile using only support length, structural-marker counts, example count and query/target arities classified family identity `72/72`. Each cell exposed one seed-invariant shape per family. The four independently authored generators contain no repeated evaluator-hidden module variable and no factorial held-out combinations. Therefore a positive pooled model can reduce to an implicit family router plus specialists, while a negative pooled model can be penalized for sharing statistics that the data-generating process never shares.

EXP-0056 tested the only subsequently constructed balanced recombination contract. It removed the shape router and supplied factorial mechanism coverage, but the shared learner reached only `0.125` overall and `0.0` minimum-combination accuracy. Its output and every declared cost were numerically identical to exact finite MDL enumeration. That result closes the exact supplied-interface mechanism; it does not repair identifiability in the original four-family worlds.

Selecting only three of the four families does not cure either defect. Shape remains deterministic for every retained family, and deleting a family cannot create a common latent variable. Padding the envelopes would hide one router while leaving the absent shared mechanism unchanged. Hand-aligning roles, fields or native sufficient statistics would move the answer into an evaluator ontology and violate the requested family-blind test.

## Decision

`blocked-by-identifiability` for another cross-family v5 or a reduced three-family wrapper over the existing generators. Do not create EXP-0057, do not implement another recurrent/dictionary/fragment/set/slot variant, and do not reactivate or tune HYP-0019, HYP-0020 or HYP-0021. This is a pre-scoring rejection of an ambiguous experiment, not evidence that universal representation learning is impossible.

The active v2 mechanism-recombination evaluator remains frozen only as preserved infrastructure. No confidence changes are justified by this service observation.

## Minimum contract for a future shared learner

A new protected data-generating contract must establish shared structure before candidate code exists:

1. At least three naturally different public observation domains must contain the same evaluator-hidden generative factors under independently sampled renderings; the factors may not be hand-aligned fields or labels exposed to candidates.
2. Training must cross factors and renderings factorially; test must hold out complete factor/rendering combinations while retaining every constituent in training.
3. Public support, query and target envelopes must make a shape-only domain/router classifier no better than chance plus `0.10` under leave-one-seed-out evaluation.
4. One lossless, domain-agnostic serialization and one unchanged fit/query/update rule must serve every anonymous slot. Test results and targets remain unavailable during meta-fit.
5. A source-identical independent ablation, no-cross-factor ablation, actual shared contextual Chow–Liu, empirical-joint and autoregressive controls, fully charged native specialists and a privileged oracle are mandatory.
6. A protected semantic fixture must require transfer of a factor into an unseen rendering and must reject family routing, nearest complete examples, finite-order Markov prediction and bounded exact enumeration. The proposed learner must have a distinct registered implementation path and cost signature from exact enumeration before scoring.
7. Overall and minimum-domain capability, shared-minus-independent transfer, acquisition, serialization, fit/search, query, update, resident/peak state, bytes moved and R1/R4/R16 workloads are mandatory Pareto axes.

## Exact next discriminating step

The next wake must remain design-only and score nothing. Audit whether the existing real whole-file compression corpus and the disjoint masked-infilling corpus contain three naturally occurring, path-hidden domains with enough files for disjoint fixed development and runner-random test roles. Test a domain-blind profile classifier and cross-domain duplicate/containment leakage. Then determine whether one common predictive-density interface can express both next-byte and masked conditional queries without task tags or evaluator-authored semantic alignment. If fewer than three domains have adequate support, if task/query form reveals the domain, or if a shared factor cannot be stated independently of file type, record rejection and pivot away from shared-representation scoring. If every gate passes, write a protected migration design and request explicit approval before changing the active evaluator; do not preregister an experiment in that same wake.
