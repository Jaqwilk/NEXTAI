## Selected discriminator

The selected question is narrower and causally distinct: can experience learn
an abstract lower bound that reduces a complete exact search while every prune
remains mechanically certified admissible? Earlier whole-I/O experiments
changed branch priority (EXP-0036) or the initial incumbent (EXP-0045). The new
role keeps both fixed and changes only the source of a certified pattern bound.
It cannot gain accuracy by approximation because the unchanged solver must
still prove the same minimum-error MDL optimum as complete enumeration.

This is a deliberately skeptical test. Certificate construction and checking,
pattern induction, rejected bounds, fallback nodes, state and bytes are all
inside the cost boundary. A learned bound that merely moves work from search
into meta-fit or verification fails.
