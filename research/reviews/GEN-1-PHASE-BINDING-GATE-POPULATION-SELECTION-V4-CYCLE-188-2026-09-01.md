# Reversible phase-code gate

The proposed phase-coded operator representation was rejected before candidate
implementation. A shared state code in which every learned operator acts by
componentwise phase multiplication makes every pair of operators commute. The
frozen mechanism-recombination development worlds do not: for each of seeds
`1501103`, `1501104`, `1501105` and `1501106`, `AB` differs from `BA` on
`140/144` states, while `AC/CA` and `BC/CB` each differ on `143/144` states.
All primitive tables are bijections.

Giving each operator its own phase basis does not rescue the principle. Exact
composition then requires a dense change-of-basis map between successive
operators, which is a full linear/table reparameterization. One-hot phase state
is exactly a permutation table. The direction therefore fails the registered
noncommutative identifiability gate rather than earning a candidate, plan or
seed. Confidence is above `0.999` for this exact algebraic rejection; it says
nothing about phase codes on genuinely commutative tasks.
