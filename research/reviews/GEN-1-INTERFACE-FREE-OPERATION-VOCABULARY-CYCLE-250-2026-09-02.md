# GEN-1 interface-free operation-vocabulary search — cycle 250

## Scope and integrity

This is one bounded no-scoring SEARCH MODE cycle. It follows the cycle-249
rejection of a common update-procedure interface and asks whether executable
operation types can instead be learned from raw observations without a supplied
DSL, action ontology or semantic adapter. It changes no hypothesis, plan,
candidate, benchmark, evaluator, runner, schema, manifest, seed or score.

This is the third consecutive no-scoring cycle. The persistent user objective
explicitly forbids forcing a scored experiment because of cycle count when no
belief-changing causal thesis exists, so the older cadence rule is overridden
for this cycle rather than satisfied with an invalid alias.

## Deduplication boundary

The proposed factor must not be any of the following already tested or named:

- a DreamCoder/Stitch-style abstraction inside a supplied DSL;
- an AlphaTensor/AlphaDev search inside a supplied game, verifier and operation
  alphabet;
- a CLRS processor using hand-aligned algorithm traces;
- a predictive-state, CSSR, bisimulation or query-generated behavioral
  quotient;
- a learned router, address, macro, grammar, VM instruction, feature map,
  optimizer, update rate or representation;
- a latent code that becomes actionable only because the evaluator supplies a
  family-specific decoder or labelled action map.

The only admissible thesis would have to learn an operation code from ordinary
observations, make that code executable with no hidden semantic adapter, and
transfer the same rule across qualitatively different substrates at full cost.

## Primary-literature contradiction

Latent-action learning is the strongest apparent contradiction.

- LAPO (`SRC-0261`) derives discrete transition codes, policies and dynamics
  from videos without action labels and later reaches strong control. However,
  execution still needs a small labelled action set or interactive alignment.
- ALPT (`SRC-0263`) reports transfer even when source and target environments
  share no action names, but it trains inverse dynamics from labelled source
  actions. It transfers an alignment procedure, not an interface-free action.
- Latent intentions (`SRC-0264`) transfer from passive and cross-embodiment
  data, but the TD objective and possible-outcome semantics are supplied and
  the product is a predictive representation, not a compiled operation.
- ILPO (`SRC-0266`) makes the boundary explicit: a latent policy learned from
  observation requires additional environment interaction to map latent codes
  to real actions.

The negative and theoretical results expose why this is not a mere
implementation gap. `SRC-0262` shows that action-correlated visual distractors
capture the latent code unless some true-action supervision is introduced.
`SRC-0265` proves identifiability only after adding demonstrator identity,
sufficiently diverse policies, shared-dynamics/rank assumptions and a small
labelled set to resolve the final global permutation. The recovered kernels are
then a mixture/NMF or inverse-dynamics object with a clear classical control.

## Causal classification

There are only two cases:

1. **No relation marker, intervention diversity or action alignment.** A code
   optimized from `(observation_t, observation_t+1)` may encode any predictable
   change, including distractors. It is not identifiable as a controllable
   operation and cannot support a causal operation claim.
2. **A marker or alignment is supplied.** Demonstrator identity, diverse
   policies, actions or a few interactions break the symmetry. The problem is
   then causally equivalent to previously reviewed relation-marked
   identifiability plus inverse dynamics, mixture decomposition, behavioral
   quotient or supervised alignment. The extra information and cost must be
   charged; it is not interface-free.

This distinction also blocks a self-serving benchmark. A generator that makes
every visible transition action-caused silently encodes the answer. Adding
distractors without a natural symmetry breaker makes the target
unidentifiable. Adding labelled controls or demonstrator tags makes the
classical decomposition the immediate explanation.

## Full-cost and cross-family gate

None of the audited work shows one small source-identical learner across three
qualitatively different natural substrates. The positive studies remain within
visual control/RL and use deep encoders, video pretraining, downstream labelled
data or environment interaction. Their reported sample efficiency does not
establish a NEXTAI full-system crossover after charging video acquisition,
representation fit, latent quantization, alignment, policy fit, query/update,
state and repeated-use horizon.

No existing NEXTAI cohort exposes a natural raw actuator consequence across
three families. Creating one would require choosing action channels and
decoders before the mechanism, violating the rule that the scientific question
must precede apparatus and the present operation-vocabulary claim.

## Observation, interpretation and uncertainty

**Observation.** Observation-only transition codes can improve downstream
control in structured visual domains. Their action semantics fail under
distractors or require policy identity, action labels, interaction or a fixed
RL objective. The latter signals make latent kernels identifiable but also
create matched classical mixture/inverse-dynamics explanations.

**Interpretation.** Interface-free operation-vocabulary acquisition is not a
valid scored thesis under current evidence. Without a symmetry breaker it is
unidentifiable; with one it is a direct causal duplicate of earlier
relation-marked quotient/alignment mechanisms. This does not claim that latent
actions are useless, only that they cannot provide the distinct NEXTAI causal
factor sought here.

- Confidence `0.98` in the two-case identifiability classification.
- Confidence `0.97` that LAPO/ALPT/ILPO do not eliminate the action interface;
  they postpone or amortize its alignment.
- Confidence `0.96` that a distractor-free local benchmark would encode the
  intended operation semantics in its generator.
- Confidence `0.94` that an identified latent-kernel test needs NMF,
  inverse-dynamics, predictive-state and behavioral-quotient controls and is
  therefore not causally new.
- Confidence only `0.35` that a future natural multi-substrate dataset could
  expose a genuinely non-equivalent operation-acquisition signal.

## Decision

`REJECT_INTERFACE_FREE_OPERATION_VOCABULARY_AS_UNIDENTIFIABLE_OR_DUPLICATE`.

Do not create a hypothesis, benchmark, protected migration or scored latent
action learner. Preserve the literature contradiction as evidence about the
necessary symmetry breaker.
