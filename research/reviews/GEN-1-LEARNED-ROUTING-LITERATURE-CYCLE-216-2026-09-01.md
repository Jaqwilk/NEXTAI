# Learned routing literature and portfolio review — cycle 216

This cadence-required review closes the same bounded cycle that scored
`EXP-20260901-0054`. It adds no hypothesis, experiment plan, benchmark,
candidate, seed or scored run. The durable portfolio now contains 93 completed
experiments: 82 quick, 11 screen and 0 deep.

## 1. What was objectively learned?

The exact learned flat address preserved local insertion and reduced unmatched-
quality search work, but accuracy collapsed from `1.0` at K=32 to almost zero
at K=3200. It lost to the source-identical dense, frozen and shuffled controls,
had R4096 K slope `0.71491 +/- 0.09854`, no matched-quality break-even and no
Pareto membership. Across the wider portfolio, K-independent query, sparse
updates, warm reuse and OOD depth have each appeared, but learned representation
plus matched capability plus full-cost advantage has not appeared together.

## 2. Which assumptions were falsified?

Pair-consistency training plus coordinate-median thresholding does not make a
useful 16-bit entity address under this cohort's 100x confusable knowledge
growth. Bounded probing cannot substitute for a representation whose collisions
preserve identity. Cheap local insertion alone is insufficient evidence of
knowledge-compute decoupling.

## 3. Which results replicated?

EXP-0054 is one-seed quick evidence and therefore is not a replication. It does
repeat the portfolio-level pattern that learned routing or representation can
obtain a narrow scaling signature while losing either matched quality or full
system cost to a simple control. The only stronger preserved positives remain
mechanism-specific results such as the three-seed WT recurrent residual and the
learned pushdown depth-transfer screen; neither supplies cross-family learned
routing evidence.

## 4. Is the portfolio trapped in one family?

The portfolio has covered compression, recurrence, program induction,
probabilistic structure, transfer, local execution and retrieval. The recent
cycles did concentrate on representation and routing because HYP-0012 is the
only testing hypothesis. Closing the exact flat-address rule avoids a tuning
loop, but another hand-designed hash is forbidden.

## 5. Are implementation details replacing principles?

They would be if key length, probes, loss coefficients, thresholds or fallback
were changed after EXP-0054. Those changes are closed. A hierarchical router is
scientifically distinct only if its causal factor is sequential conditional
partitioning with bounded visited nodes, not the same 16 independent threshold
bits arranged as a tree.

## 6. What result would most change current beliefs?

A source-identical learned representation that matches dense quality throughout
100x confusable K growth, routes through O(log K) or otherwise sublinear touched
state, inserts locally without global retraining, reaches a prospectively frozen
full-cost break-even and is not dominated by raw nearest-neighbour or a classical
metric tree would materially lower confidence in HYP-0012.

## 7. Which prior work already contains the apparent novelty?

Learned indexes already replace conventional key-to-position mappings with
models and hierarchies (SRC-0211), but assume usable key order. Differentiable
boundary trees jointly learn representations with nearest-neighbour traversal
(SRC-0212). Adaptive neural trees learn representation, routing and leaves
together (SRC-0213), while sparse tree-ensemble layers explicitly distinguish
true conditional traversal from dense soft-tree evaluation (SRC-0214). Learned
routing over similarity graphs is also established (SRC-0215). Therefore a
NEXTAI hierarchy would not be a novel architecture claim. Its value is a strict
raw-observation, local-update, full-cost falsification under controls absent from
the current portfolio.

## 8. Which next test has the highest expected information gain?

Use the unchanged `latent_entity_binding_retrieval_v2` cohort for one
prospectively frozen balanced hierarchical-router quick. Before implementation,
prove by fixture and source audit that routing decisions are sequential and
node-conditional rather than an encoding of the failed flat 16-bit key. Freeze
depth `ceil(log2 K)`, beam, split objective, optimizer, verifier, fallback,
visited-node/byte accounting and local path-only insertion. Compare an identical
encoder under dense traversal, frozen and shuffled routing, plus classical
metric-tree/raw-nearest-neighbour, local dense GRU and privileged-key controls.

The existing benchmark already supplies raw anonymous nonlinear views, K
32/320/3200, confusable distractors, local insertion and complete reuse costs;
no new benchmark or schema is justified. Success requires the same 0.02 dense
quality margin, strict frozen/shuffled gains at every K, new-fact accuracy 1.0,
R4096 slope below 0.30, matched-quality break-even and implementable Pareto
non-dominance. One negative ends the exact hierarchy without tuning; one
positive seed only authorizes unchanged three-seed replication.
