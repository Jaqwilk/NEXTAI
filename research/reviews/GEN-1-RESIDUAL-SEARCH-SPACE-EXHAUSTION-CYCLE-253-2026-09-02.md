## Adversarial literature check on the residual cells

Open-ended evolution does not resolve A1. MODES (`SRC-0277`) supplies explicit
researcher-selected novelty, complexity and ecological metrics. Hintze
(`SRC-0280`) demonstrates that a simple system can satisfy nominal
open-endedness requirements, so indefinite novelty is not itself evidence of
useful capability or scaling.

Developmental robotics is the strongest A2/A14 counterexample. The Baxter PPS
system (`SRC-0278`) learns useful reach/grasp structure without instruction or
external reward. Its causal boundary nevertheless includes joint-angle
proprioception, motor commands, visual hand masks, collision rejection,
unusual-event intrinsic motivation and a Palmar reflex. Circular reactions
(`SRC-0279`) use local unsupervised association, but supply retinal/motor maps,
spatial-frequency correspondence, direction-tuned units, geometric posture
control and a programmed body. These are valuable embodied systems, not one
ontology-free source-identical rule across unrelated families.

The literature therefore changes the wording but not the classification:
self/body structure can be learned *inside* a supplied sensorimotor substrate;
it does not make the substrate boundary or scientific success criterion vanish.

## Exhaustion admission theorem

A mechanism can reopen the space only if prospective evidence establishes all
seven conditions before implementation:

1. an ordinary observational interface not authored to expose the mechanism;
2. identical executable code and constants across at least three qualitatively
   different natural systems;
3. no family labels, semantic adapters, manual ontology or privileged support;
4. a causal ablation that removes only the learned factor;
5. classical/frozen controls that cannot create the same consequence;
6. a qualitative signature beyond marginal task score;
7. a conservative matched-quality full-cost crossover including acquisition,
   fit, updates, state, communication and reuse horizon.

No current hypothesis, cohort, literature candidate or residual assumption
passes conditions 1–5 jointly. Creating a new microbenchmark would choose the
missing semantics on behalf of the candidate and cannot repair this failure.
