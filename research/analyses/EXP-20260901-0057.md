# INTERPRETATION

The experiment isolates a modest sparse-access saving but no useful learned
representation. Pooling across families did not create meaningful transfer,
and the identical dense memory's failure shows that top-k truncation is not the
main cause: the frozen width-32 set representation and memory/output rule fail
to express the heterogeneous mappings. Strong classical probabilistic suites
solve the same frozen worlds at far higher quality.

This valid result falsifies the exact preregistered 32-slot, width-32,
top-k-four, one-head, 24-epoch sparse set-memory rule. Changing slot count,
width, loss, optimizer, epochs, output binding, routing distance, or adding
family-specific structure after seeing this outcome would be prohibited
tuning. The result does not establish that every learned sparse memory or
permutation-equivariant learner is impossible.

# ALTERNATIVE EXPLANATIONS

The fixed output-binding rule may be the dominant bottleneck rather than
sparse routing. The dense ablation supports this explanation, but replacing
the binding rule now would define a new mechanism rather than repair this
registered experiment.

One runner seed could move the small shared-minus-independent difference, but
it cannot plausibly close the roughly `0.974` accuracy gap to contextual
Chow--Liu or repair the zero minimum-family result. Replication is therefore
not information-efficient.

The classical suites use strong native probabilistic structure. That limits
external generalization of their advantage, but it is exactly the mandatory
matched-cohort alternative that the shared learner had to beat.

# DECISION
