# INTERPRETATION

The tested validation-weighted hierarchy did learn useful repository regularities, but its supposed motif hierarchy collapsed to ordinary variable-order context mixing. A simpler data-reliability-weighted context tree transferred better both before adaptation and prequentially, while avoiding the validation/meta-selection cost. The result therefore supports the classical-null explanation rather than a distinct reusable-representation principle.

The cold loss is decisive for the transfer claim: CTW's advantage exists in the first 128 scored bytes, so hierarchical cannot be rescued by arguing that its later online adaptation was the intended mechanism. The larger K=32 cells help both methods, but do not reverse the aggregate or worst-file conclusion.

This experiment rejects the current HYP-0016 mechanism on the registered corpus. It does not show that all hierarchical sequence learning is impossible, and the small visible repository limits external validity. Nevertheless, changing weights, motif extraction, corpus composition, context depth or state cap after observing this result would be post-score tuning of the same thesis.

# CONFIDENCE

- `>0.999` that hierarchical fails the registered requirement of at least `0.05` lower mean and worst-file bits/byte than every implementable control: CTW is better in both directions.

- HYP-0016 confidence falls from `0.18` to `0.06` and status becomes `dormant`, not universally falsified.

# ALTERNATIVE EXPLANATIONS

- A different hierarchical model could learn motifs longer than the evaluator's maximum six-byte public context. That would require a new contract and corpus cohort, not a patch to EXP-0044.
- The validation split may be too small to estimate mixture weights, while CTW uses a fixed evidence rule. This is precisely a cost/robustness advantage of the simpler null under the registered budget.
- Shared project boilerplate may favor local context statistics over semantic motifs. A hidden multi-repository corpus is necessary for external claims, but cannot reverse this cohort's registered failure.
- Reported operation counts and state are implementation estimates. Even if their absolute calibration moved, CTW already wins all three capability metrics and uses the same context table, so a plausible accounting correction is unlikely to rescue hierarchical.
- The generic Pareto accuracy gate is inappropriate for byte compression. A corrected report would still place CTW ahead of hierarchical on every registered axis; no re-score is needed to decide this hypothesis.

# DECISION

`discard` `hierarchical_motif_compressor` as implemented and make HYP-0016 `dormant` at confidence `0.06`. Do not replicate, promote or tune this corpus, hierarchy weights, context depths, state cap or motif rules. Preserve the plan, candidates, logs, result and all negative cells.

The valid scientific conclusion is narrow: on this immutable local repository split and one blinded segment seed, a simple context-tree mixture transfers better and more cheaply than the tested validation-weighted hierarchy. This is not evidence for an LLM successor or a universal compression claim.
