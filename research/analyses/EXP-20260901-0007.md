# INTERPRETATION

Strictly local goodness updates reduce training work relative to exhaustive
end-to-end 256-label credit assignment, but this exact one-negative,
sum-of-goodness rule does not learn a useful byte predictor. Its failure to beat
the source-identical frozen network in every preregistered cell directly fails
the conjunction, while the large gap to PPM-D and CTW shows that the issue is
substantive rather than merely the conservative tolerance.

The dense-control budget failure prevents any positive conclusion, but it does
not manufacture the negative source-identical comparison: all three neural
roles completed the same cells, and the decisive frozen-hidden gate uses only
those completed artifacts. The exact Forward-Forward byte rule should end
without changing negative construction, width, threshold, epoch, learning rate
or query rule.

# CONFIDENCE

Confidence is `0.92` that this exact layer-local goodness rule should be
discarded. The source-identical semantic fixtures passed, all neural comparisons
are paired on one hidden runner seed across nine K/D cells and five test files,
and the preregistered universal cellwise gate failed. Seed variance remains
unknown, and the dense control was incomplete, so this is not evidence against
all local-credit mechanisms or a basis for a broad architectural claim.

# ALTERNATIVE EXPLANATIONS

One deterministic wrong label supplies weak contrastive information, and the
small hidden width may limit capacity. Either could be changed only by defining
a different mechanism; changing them now would be post-result tuning. The
single repository corpus also limits external validity. The broad Pareto front
is partly an artifact of many cost axes with opposing winners, so frontier
membership alone must not be read as useful capability.

# DECISION

`discard`. Mark HYP-0032 `falsified`; do not replicate, promote or tune this
exact rule. Preserve the complete-with-failures result, the dense budget failure
and the observed local-fit-cost reduction as diagnostic history.
