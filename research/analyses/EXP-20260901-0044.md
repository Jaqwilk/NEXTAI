# INTERPRETATION

The result decisively rejects the frozen mechanism on the v13 adversarial
operation. The learner's source-identical core was built for a left-to-right
closure query: it treats a masked position as a closer to emit from the current
stack top. V13 instead masks inner pushes and leaves their future return chain
visible. The frozen query rule neither scans backward from those returns nor
represents a bidirectional constraint, so it assigns no correct top-1 byte in
any case. This is a mismatch in the preregistered computational rule, not an
infrastructure failure.

EXP-0041/0042 remain valid evidence that the same rule can extrapolate clean
closure chains beyond training depth. EXP-0044 shows that this success does
not transfer even to a recoverable inverse operation inside the same anonymous
seven-symbol grammar. The earlier signal is therefore best understood as a
narrow visibly-pushdown closure solver, not a reusable learned operator or a
general masked representation. Adding backward inference, changing the query
rule or training on push corruption would change the tested mechanism and is
forbidden as post-result rescue.

# ALTERNATIVE EXPLANATIONS

- V13 tests inverse push reconstruction rather than the closure emission named
  in the original hypothesis; failure narrows the claim but does not prove
  that all learned stacks or all bidirectional structured learners fail.
- The intact return suffix makes a reverse-pair algorithm sufficient. Such an
  algorithm was not part of the frozen learner, and adding it now would be a
  different mechanism rather than a repair of a coding defect.
- The local Python corpus and seven-symbol representation remain visible and
  narrow, so neither this negative nor the earlier positives establishes a
  general language-model scaling conclusion.
- Bidirectional Markov's small nonzero exact rate may reflect local corpus
  regularities, but its much lower bits confirms that the main's failure is not
  merely an exact-match threshold artifact.

# DECISION

point-mass, reset and left-to-right pushdown family from further tuning or
benchmark repair. Mark HYP-0050 `dormant`, preserve all earlier positive and
current negative evidence, and do not promote, replicate, combine or create a
v14 rescue. The result is scientifically valid negative evidence.
