# INTERPRETATION

The trained readout clearly learned useful byte frequency/transition structure,
as both trained roles greatly beat the frozen readout. The registered causal
intervention shows that carrying the width-16 orthogonal fading state harmed
probabilistic prediction relative to using only the current byte embedding.
The likely mechanism is destructive mixing of short discrete context in a
small continuous state, but that explanation is secondary to the paired
opposite-sign observation.

K-independent query structure and small state are real engineering properties,
yet they do not compensate for worse quality and roughly billion-operation
full workload. Formal Pareto membership on many opposing axes is insufficient
for success. The dense-control budget failure prevents promotion but does not
affect the direct recurrent/no-recurrence negative comparison, since both roles
completed every identical cell.

# CONFIDENCE

Confidence is `0.97` that this exact width-16, rho-0.9, one-epoch online-readout
reservoir should be discarded. The causal ablation is source-identical, the
effect has the wrong sign in every paired quality cell, semantic fixtures and
