# INTERPRETATION

The certified abstraction is correct and captures some pairwise constraint
interaction, but the learned co-label selector did not reliably choose a
better reusable pair than the lexicographic frozen rule. Its modest overall
node advantage over frozen was smaller than cell heterogeneity and did not pay
for training, mask construction, independent certificate checking or stored
state. The support-only selector was substantially worse, showing that one
current noisy label row is a poor source for selecting the pair, while the
fixed abstraction remained the strongest fully charged source-identical role.

This is a valid negative for the exact preregistered rule: one pair, descending
co-label agreement, exhaustive mask construction, independent exhaustive
certificate, zero incumbent and fixed branch order. Increasing the number of
patterns, changing association scores, weakening certification, selecting a
later reuse horizon or changing branch order after observing this result would
be tuning or a new thesis, not replication. The result does not falsify all
admissible abstractions or pattern databases; those are established prior art.
