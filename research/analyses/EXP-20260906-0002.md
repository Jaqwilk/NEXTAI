# EXP-20260906-0002 — MUC-01 baseline calibration

## Decision

**INCONCLUSIVE as a task-and-learned-control calibration; negative for the exact
learned baseline recipe.** The evaluator, split, runner and classical control
worked, but the preregistered transformer competence gate failed decisively.
This result does not test `delta_fast_memory_v1` and is not evidence for or
against locally updated learned memory.

## Objective observations

- One preregistered runner-random seed (`1633648558`) was realized. All 27
  candidate-by-K-by-D trials completed; integrity was true before and after.
  There was no retry or replacement registration.
- `symbolic_last_write_graph_v1` was exact in every K×D cell: overall,
  replacement, retention, unseen composition and UNKNOWN accuracy were all
  `1.0`, with zero parser failures. It passed the `>=0.995` control gate.
- `dense_transformer_v1` reached `0.189815` overall, `0.181541` replacement,
  `0.201852` retention, `0.182407` unseen-composition and `0.181481` UNKNOWN
  accuracy. It failed the frozen `0.85` overall and `0.80` replacement gates.
  Its cell accuracy fell from `0.333–0.425` at K=32 to `0.0417–0.0458` at K=512.
- `bm25_iterative_reader_v1` was the stronger learned control at `0.755093`
  overall, `0.799920` replacement, `0.825926` retention, `0.800926` unseen
  composition and `0.233333` UNKNOWN. It remained below the dense competence
  criterion and was especially weak on abstention; K=128,D=4 was `0.4417`.
- Both learned readers completed 192 frozen optimizer steps and reported
  `0.866211` lexical training accuracy. That auxiliary fit did not translate
  to the end task, so successful optimization alone is not a valid positive
  control.

No seed uncertainty is estimated. The planned one-seed calibration supports
only these deterministic cell totals; no bootstrap interval is used to rescue
a failed prospective threshold.

The learned roles also reported peak CUDA reserved memory of `423,624,704`
bytes. Estimated mean query work was `93,978,563` for the dense scan and
`3,538,944` for retrieval. The symbolic operation counter is cumulative rather
than normalized per query, so its stored `2,560` summary and derived workload
amortizations must not be compared numerically with the learned estimates.
This accounting defect is another reason the calibration is inconclusive,
although the directly measured latency/RSS ordering is unambiguous.

## Answers to the review questions

1. **Do the task and controls work?** The generator, disjoint whole-world
   split, replacement/composition strata, exact scorer and symbolic control do.
   The exact learned-control recipe does not: the dense positive control is far
   below threshold, and the retrieval reader also misses many UNKNOWN and deep
   cases. Therefore the complete comparison is not calibrated.
2. **Strongest baseline and real cost.** The disclosed symbolic last-write
   graph is both strongest (`1.0`) and cheapest by direct measurement. BM25 is
   the strongest learned baseline but is not quality-comparable. The table
   reports fit, complete worker wall time, batch-1-equivalent query timing,
   update timing, persistent state, CUDA reserve and supervisor RSS; no model or
   indexing cost is omitted from the worker boundary.
3. **Is there a concrete opening for local learned memory?** Not yet on this
   grammar. The classical map already solves replacement and composition with
   lower time and state. The observed learned deficit is text matching and
   abstention, not a demonstrated memory-update bottleneck. A local-memory
   candidate would presently be an expensive recreation of a solved rule.
4. **One next discriminating experiment.** If separately approved, create a
   version-separated `MUC-01-BASELINE-CALIBRATION-V2`, still with no memory
   candidate: implement the contract's actual one-shot 8192-token dense causal
   transformer with the frozen shared 2048-entry BPE and an explicit UNKNOWN
   decoder, correct per-query operation/amortization normalization, freeze and
   preregister it, then require the same `0.85/0.80` gates on fresh calibration
   worlds. Only a pass would justify one later delta-memory versus append-only
   mechanism experiment.

## Interpretation and confidence

High confidence (`0.98`) that the symbolic task semantics and exact scorer are
internally coherent; high confidence (`0.99`) that the exact learned recipe
failed its preregistered gates; low confidence about any architectural memory
claim because no memory candidate was run and the calibration reader is a
disclosed iterative scaffold rather than the future one-shot dense reference.
