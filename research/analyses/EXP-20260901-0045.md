# INTERPRETATION

The experiment separates correctness from utility. A learned proposal can be
placed safely before an exact proof search: incorrect proposals do not change
the optimum, and a closer incumbent measurably tightens pruning. That is a
valid implementation result, but the registered computational principle was
stronger: the learned fast path had to improve exact capability per fully
charged cost over support-local and frozen sources. It did not.

The uniform held-out program distribution provides little reusable prototype
structure. Exactly labeling meta prototypes costs far more than the modest
reduction of roughly seven nodes over the frozen zero incumbent, while nearest
prototype comparison itself almost cancels the controller savings. The simpler
frozen and one-pass support proposals preserve identical capability with lower
R1, R4 and R16 work in every cell. This is a fundamental failure of the frozen
prototype/distance/greedy rule under the declared horizons, not an evaluator or
correctness defect.
