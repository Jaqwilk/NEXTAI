# INTERPRETATION

The interface correction resolved the prior crash and produced a valid causal
comparison. The learned update is useful relative to frozen lifting and the
shared implementation is better than the classical controls on this visible
screen, but the preregistered distinguishing factor—learned multiresolution
cross-scale composition—adds no meaningful quality and is usually slightly
harmful relative to the source-identical single-scale learner. The result
therefore falsifies the exact HYP-0036 lifting principle; classical-control
outperformance cannot rescue a failed causal ablation.

No rank, basis, ridge, update scale, clipping, recursion or nearby lifting
variant should be tuned. The informative residue is only a future hypothesis
proposal: a learned local update may matter, whereas this cross-scale rule does
not. EXP-0017 is not sufficient evidence for that broader proposal because it
contains one seed and two locally visible test files.
