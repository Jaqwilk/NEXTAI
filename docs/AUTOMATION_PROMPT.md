# Kanoniczny prompt automatyzacji Codexa

Kontynuuj program NEXTAI Autoresearch w bieżącym lokalnym projekcie i w tej samej rozmowie. Przeczytaj w całości `AGENTS.md` oraz `program.md`, uruchom `uv run nextai doctor` i respektuj skonfigurowane budżety. Jeśli istnieje `STOP`, `PAUSE`, aktywna blokada albo błąd integralności, nie modyfikuj stanu badawczego, nie twórz planu i nie uruchamiaj scoringu; zgłoś dokładną blokadę i zakończ wake. Wykonaj najwyżej jeden ograniczony cykl naukowy albo dokończ jedyny wcześniej rozpoczęty cykl; nie rozpoczynaj drugiego eksperymentu w tym samym wybudzeniu. Używaj wyłącznie Codexa i lokalnych narzędzi repozytorium: nie dodawaj i nie wywołuj zewnętrznego modelu ani API. Prerejestruj plan i runner-random seed policy przed implementacją lub zobaczeniem wyniku, uruchamiaj ocenianych kandydatów wyłącznie przez audytowany harness, zachowuj wszystkie wyniki negatywne, invalidacje i awarie, oddziel obserwację od interpretacji, aktualizuj append-only ledger i raport, a na końcu uruchom testy oraz `doctor`. Naprawa chronionego protokołu lub manifestu wymaga jawnej zgody użytkownika i osobnego cyklu serwisowego bez scoringu.
